# TimyCue（仮）

カレンダーは予定を書く。TimyCue は予定に間に合わせる。

予定時刻・場所・現在地・移動手段などから「何時に出ればいいか」を伝える iPhone アプリ（SwiftUI、iOS 17 以上、iPhone のみ）。

仕様は [docs/spec.md](docs/spec.md)（v1.2）。コードの「仕様 §N」はその番号、「Q1」などは spec.md の「決まったことの記録」を指す。

## いまの段階

第 2 段階：カレンダータブの月カレンダー（週を途切れず縦に連続表示・左端の月表示列と固定表示・上部の年・曜日固定・今日の丸・予定の出し方・重ならない吹き出し 2 つ）と 1 日タイムライン（指の位置を中心にピンチで拡大・現在時刻の線・重なる予定の横分け・終日専用帯）、予定詳細の吹き出し（月カレンダーは一覧の吹き出しの中で切り替え、タイムラインは予定ブロックの近く）まで。
第 3 段階の前半：予定登録・編集・コピーの 3 分割画面の骨組み（下の日付カレンダーと年月バー、日付タブ、入力の各行、保存・閉じる・削除・コピー）。月カレンダー右下と 1 日タイムライン右上の「＋」、予定詳細の吹き出しの「編集」から開き、保存したら元の画面へ戻る。「時」を押すと分ホイール、仮予定は上下にドラッグ・下端のハンドルで終了。ホームは仮の画面。
第 3 段階の後半：予定名・場所の入力の候補と、予定の重なりの警告（「予定が重複」「前の予定の終了時刻未設定」。保存は止めない）。
第 4 段階：Apple カレンダー（EventKit）との同期。許可は、未連携のときの案内で「カレンダーを連携」を押したときに求め（Q38。カレンダータブを開いただけでは求めない）、つないだら作成・編集・削除を Apple カレンダーへ反映し、Apple カレンダー側の変更も読み込む。読み込む範囲は表示に必要な分だけ。設定 ＞ カレンダー連携 で、既定の保存先と読み込むカレンダーを選べる（設定トップの行の右に「接続済み」などの状態。既定の保存先が使えなくなったら iPhone の既定へ切り替えて一度だけ知らせる）。Apple カレンダーの予定は画面の処理の外で読む。つないでいない間は端末の中のファイルに保存し、つないでも端末の予定を Apple カレンダーへ移さない。TimyCue だけの情報（到着目標・移動手段・通知など）は別のファイル。DEBUG のビルドは見本の予定でつながない（`TimyCue/Data/SampleEvents.swift`。起動引数 `-TimyCueRealData YES` で本物の保存先）。位置情報・天気・Live Activity にはまだ繋いでいない。繰り返し予定（Q37・Q44）は第 4 段階の後半。
繰り返し予定は Apple カレンダーの繰り返しを正本にし（Q37 の変更）、直す・消すときは この予定のみ／これ以降／すべて を選ぶ（Q44）。
初期ホーム：次の予定 1 件と、未連携のときの［カレンダーを連携］［予定を登録］（Q42-8・Q43）。出発時刻・時計・移動中は第 5 段階から。
TestFlight：Codemagic の「iOS → TestFlight」で送り、iPhone の実機で確かめている（手順は docs/ios-release.md）。

## 構成

| 場所 | 役割 |
|---|---|
| `project.yml` | XcodeGen の設定。Xcode プロジェクトは Git に入れず、ここから作る |
| `TimyCue/App/` | 入口と下部タブ |
| `TimyCue/DesignSystem/` | 色・角丸・余白（値は仮。決まったらここだけ差し替える） |
| `TimyCue/Model/` | 予定のデータ。Apple カレンダーと共有する部分（`CalendarEvent`）と TimyCue だけの情報（`TimyCueEventMetadata`）を分けて持つ（仕様 §84） |
| `TimyCue/Data/` | 予定の読み書き：端末の中のファイル（`FileRepositories.swift`）と Apple カレンダー（`EventKit/`）。見本の予定 |
| `TimyCue/Prediction/` | 「予測で一括」の入口（今はモック） |
| `TimyCue/Features/Calendar/` | カレンダータブ：週を縦につなげる月カレンダー・日付吹き出し・1 日タイムライン（`CalendarStore`。仕様 §18〜§30・v1.1・Q8〜Q20） |
| `TimyCue/Features/Settings/` | 設定タブ（今は 設定 ＞ カレンダー連携 だけ。§81・Q31〜Q33） |
| `TimyCue/Features/EventDetail/` | 予定詳細の中身（吹き出しの中に出す。編集は「編集」から 3 分割画面へ。v1.1・Q27〜Q30） |
| `TimyCue/Features/ScheduleEditor/` | 3 分割の予定編集画面（`ScheduleEditorStore`。仕様 §31〜§67・v1.1 の下カレンダーと年月バー） |
| `TimyCueTests/` | 自動テスト |
| `tools/make_icon.py` | 仮のアプリアイコンを作る（`python tools/make_icon.py`） |
| `codemagic.yaml` | クラウドの Mac でのビルド・テスト・画面写真・TestFlight 送信 |
| `docs/ios-release.md` | Mac なしで App Store に出す手順 |

## 作り方の決まり

- 仕様にない画面や動きは足さない。仕様の【未決】は勝手に決めず、確認してから作る。
- 月カレンダーの吹き出し間のドラッグ＆ドロップによるコピーは**廃止。作らない**。予定の新規・編集・移動・コピーは 3 分割画面に集める。
- 状態は画面に直書きせず、Store に置く。大きな View を 1 ファイルに詰め込まない。
- 色・フォントサイズ・3 分割の比率・目盛りの間隔などは未決なので、あとで変えやすい形にしておく。

## ビルドと確認

Mac がないので、Codemagic の「iOS ビルド確認（署名なし）」でビルド・自動テスト・シミュレータの画面写真まで確かめる。
iPhone で触るときは「iOS → TestFlight」。手順は `docs/ios-release.md`。
