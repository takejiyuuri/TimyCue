# デザインの気になる点メモ

実機（TestFlight）やシミュレータの画面写真で気づいた、見た目・使い心地の点を書き留めておく一覧。
細かなデザインの調整は、ホーム・拡大表示などの画面がそろってから「デザインを整える回」でまとめて直す。
ただし、見て分かる崩れや、試すこと自体の邪魔になるもの（読めない・押せない）は、不具合の修正と一緒にすぐ直す。

色・文字の大きさ・3 分割の比率などは仕様（§86・Q26）で「実機で確かめて決める」とされている。
値は `TimyCue/DesignSystem/`（`Theme.swift`・`CalendarMetrics.swift`・`TimelineMetrics.swift`・`EditorMetrics.swift`）にまとめてある。

## 書き方

- 気づいたら、日付・画面・どう見えたか・どうしたいか（分かれば）を 1 行で足す。写真があれば `docs/design-notes/` に置いて名前を書く。
- 区分：**すぐ**（崩れ・読めない・押せない）／**まとめて**（好み・釣り合い・細かな値）／**実機で**（実機で確かめてから決める）
- 状態：未着手／対応中／済み（済みにしたら、直したコミットか PR を書く）
