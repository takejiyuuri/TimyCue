## 正式なデザインの基準：キャラクター 3 モード（2026-10-16 確定）

「TimyCue キャラクター 3 モード（うさぎは被り物バージョン）」の画像を、新しい正式デザインの**正本**にする（spec §88.4）。これ以上、別のデザインの候補は作らない。この原画を基準に、これから SwiftUI で再現する（実装は別に指示があってから）。

| turtle-mode-poses.png・human-mode-poses.png・rabbit-mode-poses.png | 各モードの「主なポーズ・動作例」の段（ラベルつき） |

- 切り出しは原画の画素をそのまま四角く切り取っただけで、形・色・比率は変えていない（縮めたり色を変えたりしていない）。吹き出し・音符・動きの記号が入らない範囲で切ったので、まわりにパネルの淡い背景と足元の影が少し残っている。
- 亀・人型・うさぎの 3 モードは、すべて同じキャラクター。甲羅とうさぎの耳の被り物（フード）は、着けたり外したりする装備。
- **うさぎモードの間は、被り物の耳を必ず付ける。** 原画には、うさぎモードで耳が付いていない姿（主なポーズの「急ぎ足」「バッグを持つ」、表情・仕草の「走る」）があるが、設定は被り物の耳なので、耳は外さない（2026-10-16 ユーザー）。
- 画像の中の吹き出し・背景・床の影・音符・動きを表す記号は、キャラクター本体に要るものではない。
- モードの切り替えの時刻（亀＝出発 61 分以上前、人型＝60〜31 分前、うさぎ＝30 分前〜出発時刻）は、原画の「第一候補」のとおり採用（spec Q89）。見た目のモードと時間帯ごとの動作（spec §88.7）は分けて扱い、うさぎモードになっただけで強く焦らせない。場所なしの予定・出発のあと・移動中・到着のあと・予定がないときのモードは spec §88.4（Q90）。
- 大きさは Home で 36pt が第一の候補。甲羅・耳を含めた必要な領域は実機で調整する。動きは控えめでなめらかに。

## 新キャラクター 3 案（比較候補。2026-10-16 Claude 制作。採用せず、履歴）

「新キャラクター3案制作・比較指示書」（2026-10-16）で作った比較候補。同じ日に、正式なデザインはキャラクター 3 モードの原画に決まり、この 3 案には置き換えない（履歴として残す）。H2 の配置と H3 の動きの仕様も変えていない。アプリのコードには組み込んでいない。

- 方向：小さくて親しみやすく、少ない線で愛嬌を出す（既存のキャラクターの形や顔はまねない）。白〜アイボリーの体、やわらかいブラウンの輪郭（少し揺らした手描きふうの線）、小さな点の目、ほっぺ・口なし、短い手足、無地の背景、リュック・床・影なし。小物はコーヒーのときのカップと湯気だけ。
- 3 案は輪郭と体の作りから描き分けた。A まんまる：大きな丸い頭（あごの線あり）と小さな胴、ちょこんとした手足。B もちもち：頭と体がひと続き（あごの線なし）で、やわらかいくびれと、下がふっくら広い体。C すっきり・やさしい：少し縦長で、丸い頭と細めの胴・腕・脚がはっきり分かれる。
- どれも頭・胴・腕・脚・小物を部品に分けて描いている（あとで歩く・座る・飲む・運ぶなどの動きを足せる形）。
- 原画は 3 案とも同じ倍率（立った姿の全身の高さをそろえ、座る・コーヒーも同じ縮尺。足元をそろえる）。

## 画像から測ったこと（2026-10-15 Claude）

- A（コンパクト）の人型：画面の幅を 390pt として換算すると、座った姿で高さ約 40pt・頭の幅約 28pt。仕様の「24pt 前後」より大きい。→ Q79 で決定（2026-10-15）：H1 では 16・24・36pt と約 40pt を比べる。「○pt」は小物を除いた体の全身の高さで、座った姿・立った姿を同じ姿どうしで比べる。約 40pt は推定で、正式な寸法ではない。
- A の時計は画面の幅の約 30％。仕様の時計は初め 74％（§88.3）で、大きさの基準にするのは人型だけ。

## 参考にするもの・しないもの（2026-10-15 決定）

- 参考にする：キャラクターの形（A'）と表情の方向（目だけで、仕草で気持ちを出す）、動き、大きさの感じ。日常の動作・時計の出現・移動の演出の例。時計の出現の 10 秒の流れの例。
- 再現しない：背景の描き込み（ソファ・机・植物・照明・建物・道路）、足元の床や影、リアルな乗り物（丸みのあるシンプルなデフォルメにする）。背景は Home と同じ無地のアイボリー。
- 残す：時間を分かるための UI（タイムラインの線・予定の印など）。
