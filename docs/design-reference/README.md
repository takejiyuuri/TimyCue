# デザインの参考画像（Home の作り直し・人型キャラクター）

> 2026-10-15 に受け取った H1 用の参考画像。**見た目の参考資料で、アプリの画像素材には使わない**（spec.md §88.4）。
> 画像と仕様が食い違うときは **spec.md §88 を優先する**。画像を置いただけでは実装を始めない（H1 の実装とビルドは別に指示があってから）。

| ファイル | 呼び名 | 何の基準か |

## 画像から測ったこと（2026-10-15 Claude）

- A（コンパクト）の人型：画面の幅を 390pt として換算すると、座った姿で高さ約 40pt・頭の幅約 28pt。仕様の「24pt 前後」より大きい（spec.md の未決 Q79）。
- A の時計は画面の幅の約 30％。仕様の時計は初め 74％（§88.3）で、大きさの基準にするのは人型だけ。

## 画像の中で仕様と違うもの（仕様どおりに作る）

| 画像 | 仕様 |
|---|---|
| 人型がいつもリュックを背負っている | リュックは常に背負わせない。小物は場面に応じて、動作に必要な最小限（§88.4） |
| ソファ・照明・植物・建物などの背景 | 背景は原則無地。家具・植物・建物などを常に置かない（§88.4） |
| 下のタブが「ホーム・予定・＋・地図（記録）・その他」 | 下のタブは今のまま「ホーム・カレンダー・設定」（§3）。Home に常設の＋は置かない（Q21・Q43） |
| 右上のベルのマーク、あいさつの文（「おはようございます」など） | 仕様にないので入れない |
| 画面の上に日付がない | いちばん上は今日の日付（§88.2） |
| 時計の形（グラデーションのリングと数字だけ、針と弧だけ など） | 時計の形・針・リング・中央の数字は今の決まりのまま（§6・追加仕様書 §44・§88.3） |
| 「出発してください」が予定の行の下に小さく出る | 主状態の大きな知らせは演出帯に出す（§88.3） |
| 出発時刻に乗り物のそばへ行く（「出発時刻／乗り物へ」） | 推奨出発時刻になっただけでは乗らない。乗る演出は実際の移動開始の判定のあと。出発時刻は出発を促す動作（§88.7） |
| 乗り物の演出がバスと電車で別 | v1 の公共交通の演出は 1 種類（§88.7） |
| カラーパレットの「#F8BD3C メインオレンジ」 | 正しくは #FB8D3C（ブランドのパレット。追加仕様書 §46.4）。色見本の色も #FB8D3C に近い |
| タイムラインに出発の点がない | 推奨出発時刻があれば出発の点を出し、予定と見た目でつなぐ（§88.2） |
